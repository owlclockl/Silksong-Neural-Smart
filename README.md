## 🌟 Ключевые возможности (Key Features)

- 🧠 **Собственная сверхбыстрая нейросеть (Pure C# Neural Engine)**:
  - Нулевая зависимость от тяжелых внешних C++ библиотек (PyTorch / ONNX).
  - Инференс занимает **менее 0.02 мс** (свыше 50,000 решений в секунду), гарантируя гладкий геймплей без просадок FPS.
  - Входной вектор из **24 сенсоров** (пространственные лучи, дистанции, скорости, тайминги, хитбоксы, ловушки, статус шелка/выносливости).
  - Выходной вектор из **10 действий** (перемещение, прыжки, рывки, удары, пого-отскоки, парирование, лечение).

- ⚖️ **Интеллектуальная система баланса (Fair-Play Balancing Engine)**:
  - Имитация естественной реакции человека (**110–140 мс**) через кольцевой буфер восприятия.
  - Ограничение выносливости (Stamina budget) и телеграфирование атак противников.
  - Настраиваемый процент тактических ошибок (Mistake margin).
  - Динамическая подстройка сложности (DDA) — бои ощущаются живыми, тактическими и честными!

- 🏟 **НОВОЕ · Режим «Великая Арена» (Grand Arena) — отдельный режим со своими сохранениями**:
  - **Кнопка прямо в главном меню игры** — «🏟 ВЕЛИКАЯ АРЕНА (ОБУЧЕНИЕ МОБОВ И ХОРНЕТ)» (или клавиша **F6**).
  - **Мобы и Хорнет обучаются ОДНОВРЕМЕННО на одной большой арене** (80 × 32 юнита, 2 ямы с шипами, 18 платформ, 8 точек спавна).
  - До **8 мобов всех 4 архетипов сразу** против Хорнет: каждый боец стаи оценивает **свой геном** — за один раунд эволюционируют сразу 5 популяций (Хорнет + 4 архетипа).
  - **Система волн**: побеждает Хорнет → волна растёт, стая усиливается и становится многочисленнее; побеждает стая → волна снижается.
  - **Честный баланс урона стаи** — урон каждого моба масштабируется по размеру стаи, чтобы численный перевес не превращался в мгновенную смерть.
  - **3 независимых слота сохранения режима** (мозги + статистика + волна + время игры), автосохранение каждые 5 раундов и быстрое сохранение по **F5**.
  - Живой обзор арены, вероятности действий и график фитнеса «Хорнет против стаи» прямо в HUD.

- 🥋 **Тренировочный режим «Silk Dojo» (The Training Arena)**:
  - Отдельный режим обучения по горячей клавише **F7** с изолированными тренировочными комнатами.
  - **3 уникальные комнаты**:
    1. *Арена Мха (Moss Flat Dojo)* — базовый зонинг, размен ударами и контроль дистанции.
    2. *Вертикальный Разлом (Vertical Chasm with Spikes)* — яма с шипами, обучение Пого-прыжкам и лазанию по стенам.
    3. *Испытание Цитадели (Citadel Trial)* — колонны, узкие проходы и динамические препятствия.

- 👑 **Обучение Хорнет (Autonomous Hornet Agent)**:
  - Режим самообучения (Self-play) для Хорнет с адаптивным расходом катушек шелка, выбором моментов для лечения и воздушными Пого-комбо.
  - Возможность тренировки **AI vs AI** (наблюдение) или **Player vs AI** (игрок лично сражается против обучаемой нейросети).

- 📊 **Визуализация и статистика в реальном времени**:
  - Live HUD с графиком нейросети, весами синапсов, вероятностями действий и кривой эволюции (Fitness Curve).
  - Ускорение симуляции от **1x** до **50x** для быстрой эволюции десятков поколений за минуты.
  - Экспорт и импорт весов в формате `.brain.json`.

- 🌐 **Интерактивный веб-симулятор (Web Live Simulator)**:
  - Полноценная 2D боевая арена с физикой Silksong в браузере на порту `3000` для визуального тестирования ИИ прямо сейчас!
  - **Точная копия главного меню мода**: те же две кнопки — «Великая Арена» и «Классическое додзё 1 на 1», те же 3 слота сохранений (в `localStorage`).

- 🔨 **Сборка в один клик (`build.bat`)**:
  - Находит установленную Silksong сама (аргумент → `SILKSONG_PATH` → `silksong.path.txt` → реестр Steam → `libraryfolders.vdf` → скан дисков C–G).
  - Собирает `.dll`, кладёт рядом предобученные мозги и документацию, пакует готовый `.zip` и (по флагу `--deploy`) сразу ставит мод в игру.

## 🎮 Горячие клавиши в игре

| Клавиша | Функция |
|---|---|
| `F6` | 🏟 **Великая Арена**: открыть панель режима (выбор слота / старт) или свернуть HUD режима |
| `F5` | 💾 Быстрое сохранение активного слота Великой Арены |
| `F7` | Показать / скрыть интерфейс обучения додзё (Neural HUD) |
| `F8` | Переключить автономный ИИ для Хорнет (AI / Player) |
| `F9` | Мгновенно перезапустить текущий раунд |
| `Page Up` | Увеличить скорость симуляции (1x → 2x → 5x → 10x → 25x → 50x) |
| `Page Down` | Уменьшить скорость симуляции |

Ручное управление Хорнет в Великой Арене (когда ИИ выключен по `F8`):
`A`/`D` или `←`/`→` — бег, `Space`/`K` — прыжок, `LeftShift`/`L` — рывок, `J` — удар,
`S`/`↓` — удар вниз (пого), `O` — парирование, `U` — лечение шелком.

## 🔨 Сборка мода в один клик (Windows)

В корне репозитория лежит `build.bat` — он компилирует **всё** в готовый мод:

```bat
:: обычная сборка — результат в dist\
build.bat

:: собрать И сразу установить в игру (Steam-путь ищется автоматически)
build.bat --deploy

:: если игра лежит в нестандартном месте
build.bat --deploy --game "D:\Games\Hollow Knight Silksong"

:: сборка под BepInEx 6 IL2CPP
build.bat --il2cpp --deploy
```

| Флаг | Действие |
|---|---|
| `--deploy`, `-d` | Скопировать готовый мод в `<Игра>\BepInEx\plugins\SilksongNeuralSmart\` |
| `--game PATH`, `-g PATH` | Явно указать папку с игрой |
| `--il2cpp` | Сборка под BepInEx 6 IL2CPP (`netstandard2.1`) вместо `net472` |
| `--debug` | Конфигурация Debug |
| `--clean` | Полная пересборка с нуля |
| `--no-zip` | Не создавать архив |
| `--no-pause` | Не ждать нажатия клавиши (для CI) |

Результат сборки:

```
dist\
├── BepInEx\plugins\SilksongNeuralSmart\
│   ├── SilksongNeuralSmart.dll
│   ├── PretrainedBrains\*.brain.json
│   ├── README.md, MANUAL_RU.md
└── SilksongNeuralSmart-net472-Release.zip   <- готово к раздаче
```

Скрипт сам находит игру: аргумент `--game` → переменная `SILKSONG_PATH` → файл `silksong.path.txt` →
реестр Steam → `libraryfolders.vdf` → перебор стандартных путей на дисках C–G.
На Linux / macOS используйте `./build.sh` (те же флаги).

## 🚀 Установка

1. Скачайте и установите **BepInEx 5** (Mono) или **BepInEx 6 IL2CPP** для *Hollow Knight: Silksong* и один раз запустите игру, чтобы BepInEx создал свои папки.
2. Запустите `build.bat --deploy` — мод соберётся и установится сам.
   Либо вручную: распакуйте `dist\SilksongNeuralSmart-*.zip` в корень папки игры (там уже есть структура `BepInEx\plugins\...`).
3. Запустите игру.
4. В **главном меню** появится кнопка **«🏟 ВЕЛИКАЯ АРЕНА (ОБУЧЕНИЕ МОБОВ И ХОРНЕТ)»** — выберите один из 3 слотов и начните обучение.
   Кнопка не видна? Нажмите **F6**. Для классического додзё 1 на 1 — **F7**.
